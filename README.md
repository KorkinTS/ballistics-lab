# Ballistics Lab

Интерактивный график движения тела, брошенного под углом к горизонту. Изменяйте исходные данные, выбирайте точки на кривой и нажимайте на названия величин, чтобы увидеть их формулы.

## Запуск

Откройте `index.html` в браузере. Сборка и установка пакетов не требуются. Для GitHub Pages используется корень ветки `main`.

## Модель

Начало координат лежит на земле под точкой запуска. В модели с сопротивлением действует линейная сила **F = −mk v**, где **k** задаётся в с⁻¹. Координаты вычисляются по аналитическим формулам. Время столкновения с землёй для **k > 0** находится методом бисекции. При включённом сопротивлении пунктир показывает полёт с теми же начальными условиями при **k = 0**.

По горизонтали и вертикали график автоматически подбирает масштабы. Чтобы выбрать точку клавиатурой, переведите фокус на график и воспользуйтесь стрелками. Enter закрепляет точку, Escape снимает закрепление.
